## 1. Подготовка и запуск проекта

1. Откройте рабочее пространство проекта (`javafx-project.code-workspace`) в **VSCodium / VS Code**.
2. Убедитесь, что проект собирается и запускается:
   - Откройте файл `src/com/example/App.java`.
   - Нажмите зелёную кнопку **`▶ Run`** (или `F5`).
   - Должно появиться тестовое окно JavaFX. Закройте его.

## 2. Вёрстка интерфейса в Scene Builder

Мы создадим понятный и наглядный двухчисловой калькулятор:
- Поле для ввода первого числа;
- Поле для ввода второго числа;
- Панель кнопок операций: `+`, `-`, `*`, `/`, `C` (очистка);
- Метка (Label) для вывода результата или ошибки.

### Шаг 2.1: Открытие макета
1. В VSCodium в верхнем меню выберите **Terminal → Run Task... → 🎨 Открыть макет в Scene Builder**  
   *(либо откройте файл `src/com/example/MainView.fxml` правой кнопкой мыши через Scene Builder)*.
2. Откроется окно Scene Builder.

### Шаг 2.2: Создание структуры элементов
В левой нижней панели **Hierarchy** (Иерархия):
1. Внутри корневого элемента `VBox` удалите старые элементы (кликните и нажмите `Delete`).
2. В левой верхней панели **Library** найдите и перетащите в `VBox`:
   - **TextField** (Поле ввода 1)
   - **TextField** (Поле ввода 2)
   - **HBox** (Горизонтальный контейнер для кнопок)
     - Внутрь `HBox` перетащите 5 кнопок **Button**: `+`, `-`, `*`, `/`, `C`.
   - **Label** (Метка для вывода результата).

> 💡 **Совет по оформлению (Layout):**
> - Выберите корневой `VBox`, в правой панели **Layout** установите `Alignment` = `CENTER`, `Spacing` = `15`, `Padding` = `20`.
> - Выберите `HBox` с кнопками, установите `Alignment` = `CENTER` и `Spacing` = `10`.
> - Для `TextField` можно установить `Pref Width` = `200`.

## 3. Связывание с Java-кодом (Magic Auto-Sync)

Чтобы элементы интерфейса были доступны в коде, им нужно назначить:
1. **fx:id** — имя переменной в Java, через которую код читает значение или меняет элемент.
2. **On Action** — имя Java-метода, который сработает при нажатии на кнопку.

### Шаг 3.1: Назначение fx:id
В правой панели Scene Builder раскройте секцию **Code**:
- Выберите первое поле `TextField` ➡️ в поле **`fx:id`** напишите: `num1Field`  
  *(во вкладке Properties можно указать `Prompt Text`: `Первое число`)*.
- Выберите второе поле `TextField` ➡️ в поле **`fx:id`** напишите: `num2Field`  
  *(во вкладке Properties можно указать `Prompt Text`: `Второе число`)*.
- Выберите `Label` (результат) ➡️ в поле **`fx:id`** напишите: `resultLabel`  
  *(во вкладке Properties задайте `Text`: `Результат: `)*.

### Шаг 3.2: Назначение On Action (обработчики событий)
Для каждой кнопки в секции **Code** укажите соответствующий метод в поле **`On Action`**:
- Кнопка `+` ➡️ `onAdd`
- Кнопка `-` ➡️ `onSubtract`
- Кнопка `*` ➡️ `onMultiply`
- Кнопка `/` ➡️ `onDivide`
- Кнопка `C` ➡️ `onClear`

> ⚠️ **Проверка контроллера:** Убедитесь, что в левой нижней панели в блоке **Controller** у вас указан класс:  
> `com.example.MainController`

### Шаг 3.3: Сохранение и автоматическая синхронизация
1. В Scene Builder нажмите **Ctrl + S** (File → Save).
2. Переключитесь обратно в окно **VSCodium** и откройте файл `src/com/example/MainController.java`.
3. В строке состояния VSCodium (внизу) появится уведомление:
   `$(sync) JavaFX: MainController.java auto-synced`
4. **Готово!** Расширение само создало поля `@FXML private ...` и сгенерировало заготовки методов.

## 4. Реализация логики калькулятора

Откройте файл `src/com/example/MainController.java` и дополните сгенерированные методы логикой вычислений.

### Итоговый код `MainController.java`:

```java
package com.example;

import javafx.fxml.FXML;
import javafx.scene.control.Label;
import javafx.scene.control.TextField;

public class MainController {

    @FXML
    private TextField num1Field;

    @FXML
    private TextField num2Field;

    @FXML
    private Label resultLabel;

    // Вспомогательный метод для выполнения вычислений
    private void calculate(char operator) {
        try {
            // Считываем значения из полей и переводим в числа с плавающей точкой
            double a = Double.parseDouble(num1Field.getText().trim());
            double b = Double.parseDouble(num2Field.getText().trim());
            double res = 0;

            switch (operator) {
                case '+':
                    res = a + b;
                    break;
                case '-':
                    res = a - b;
                    break;
                case '*':
                    res = a * b;
                    break;
                case '/':
                    if (b == 0) {
                        resultLabel.setText("Ошибка: Деление на ноль!");
                        return;
                    }
                    res = a / b;
                    break;
            }

            // Форматируем и выводим результат
            resultLabel.setText(String.format("Результат: %.2f", res));

        } catch (NumberFormatException ex) {
            // Срабатывает при вводе некорректных символов или пустых строках
            resultLabel.setText("Ошибка: Введите корректные числа!");
        }
    }

    @FXML
    void onAdd() {
        calculate('+');
    }

    @FXML
    void onSubtract() {
        calculate('-');
    }

    @FXML
    void onMultiply() {
        calculate('*');
    }

    @FXML
    void onDivide() {
        calculate('/');
    }

    @FXML
    void onClear() {
        num1Field.clear();
        num2Field.clear();
        resultLabel.setText("Результат: ");
        num1Field.requestFocus(); // Возвращаем фокус на первое поле
    }
}
```

## 5. Тестирование и запуск

1. Сохраните изменения в `MainController.java` (**Ctrl + S**).
2. Запустите проект через `App.java` (**`Run`** или `F5`).
3. Проверьте основные сценарии:
   - **Сложение:** `12.5` + `7.5` = `20.00`;
   - **Вычитание:** `10` - `15` = `-5.00`;
   - **Умножение:** `4` * `2.5` = `10.00`;
   - **Деление на 0:** `5` / `0` = *Ошибка: Деление на ноль!*;
   - **Некорректный ввод:** `abc` + `5` = *Ошибка: Введите корректные числа!*;
   - **Кнопка C:** поля очищаются, результат сбрасывается.
