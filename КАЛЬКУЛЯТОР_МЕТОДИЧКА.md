# 📱 Лабораторная работа: Создание классического калькулятора (Grid / Мобильный стиль)

**Цель работы:**
- Спроектировать адаптивный мобильный интерфейс калькулятора в **Scene Builder** с использованием сетки **GridPane**;
- Освоить назначение `fx:id` и группировку обработчиков событий `On Action`;
- Использовать автоматическую синхронизацию (**JavaFX Controller Auto-Sync**) для мгновенного обновления контроллера;
- Реализовать логику классического пошагового калькулятора (ввод цифр, точки, смены знака, сохранение промежуточного операнда и операция равенства).

---

## 📱 Внешний вид макета (Сетка 4x5)

Интерфейс строится по образу стандартных калькуляторов iOS / Android:

```text
┌───────────────────────────────┐
│                     [ 105.5 ] │  ← Экран (displayLabel / TextField)
├───────┬───────┬───────┬───────┤
│   C   │  +/-  │   %   │   /   │  ← Ряд 0
├───────┼───────┼───────┼───────┤
│   7   │   8   │   9   │   *   │  ← Ряд 1
├───────┼───────┼───────┼───────┤
│   4   │   5   │   6   │   -   │  ← Ряд 2
├───────┼───────┼───────┼───────┤
│   1   │   2   │   3   │   +   │  ← Ряд 3
├───────┴───────┼───────┼───────┤
│       0       │   .   │   =   │  ← Ряд 4 (кнопка 0 занимает 2 колонки)
└───────────────┴───────┴───────┘
```

## 1. Вёрстка интерфейса в Scene Builder

### Шаг 1.1: Открытие макета
1. В VSCodium нажмите **Terminal → Run Task... → 🎨 Открыть макет в Scene Builder**.
2. В панели **Hierarchy** (слева внизу) удалите все старые дочерние элементы из корневого контейнера.

### Шаг 1.2: Создание базовой структуры (VBox + GridPane)
1. Выберите корневой **VBox**:
   - В панели **Properties / Layout** справа:
     - `Alignment`: **CENTER** (или **TOP_CENTER**);
     - `Spacing`: **15**;
     - `Padding`: **15** со всех сторон;
     - `Pref Width`: **320**, `Pref Height`: **480**.
2. Внутрь `VBox` перетащите из библиотеки слева (**Library**):
   - **Label** (или **TextField**) для дисплея калькулятора;
   - **GridPane** (сетка для кнопок).

### Шаг 1.3: Настройка дисплея
- Выберите `Label`:
  - Вкладка **Properties**:
    - `Text`: **0**
    - `Alignment`: **CENTER_RIGHT** (прижато к правому краю)
    - `Font`: размер **32px** (Bold)
    - `Pref Width`: **280**
    - `Pref Height`: **60**
- Вкладка **Code** (справа):
  - **`fx:id`**: `display`

### Шаг 1.4: Настройка сетки GridPane
- По умолчанию в `GridPane` может быть 3x2 ячеек. Нам нужна сетка **4 колонки на 5 строк**.
  - Чтобы добавить строку/колонку: нажмите правой кнопкой мыши по сетке ➔ **GridPane ➔ Add Row Above / Below** или **Add Column**.
- В свойствах `GridPane`:
  - `Hgap`: **10** (расстояние между кнопками по горизонтали);
  - `Vgap`: **10** (расстояние между кнопками по вертикали);
  - `Alignment`: **CENTER**.

### Шаг 1.5: Размещение кнопок по ячейкам

Перетащите кнопки **Button** в каждую ячейку сетки и задайте им размеры (рекомендуется выделить все кнопки и задать `Pref Width` = `60`, `Pref Height` = `60`, размер шрифта `18px`).

> 💡 **Элегантный приём:** Чтобы не писать 10 отдельных методов для каждой цифры, всем цифровым кнопкам назначается **один общий метод** `onDigitClick`, а текст цифры берётся прямо с нажатой кнопки!

| Ряд | Колонка 0 | Колонка 1 | Колонка 2 | Колонка 3 |
|---|---|---|---|---|
| **0** | Button: `C`<br>On Action: `onClear` | Button: `+/-`<br>On Action: `onToggleSign` | Button: `%`<br>On Action: `onPercent` | Button: `/`<br>On Action: `onOperator` |
| **1** | Button: `7`<br>On Action: `onDigitClick` | Button: `8`<br>On Action: `onDigitClick` | Button: `9`<br>On Action: `onDigitClick` | Button: `*`<br>On Action: `onOperator` |
| **2** | Button: `4`<br>On Action: `onDigitClick` | Button: `5`<br>On Action: `onDigitClick` | Button: `6`<br>On Action: `onDigitClick` | Button: `-`<br>On Action: `onOperator` |
| **3** | Button: `1`<br>On Action: `onDigitClick` | Button: `2`<br>On Action: `onDigitClick` | Button: `3`<br>On Action: `onDigitClick` | Button: `+`<br>On Action: `onOperator` |
| **4** | Button: `0` *(Column Span = 2)*<br>On Action: `onDigitClick` | *(объединено с 0)* | Button: `.`<br>On Action: `onDot` | Button: `=`<br>On Action: `onEquals` |

> 📌 **Как объединить кнопку `0` на 2 колонки:**  
> Выберите кнопку `0` в панели **Layout** справа и укажите параметр **Column Span: 2**. Ширину `Pref Width` для кнопки `0` установите **130**.

## 3. Реализация логики в `MainController.java`

Замените содержимое файла `src/com/example/MainController.java` следующим чистым и понятным кодом:

```java
package com.example;

import javafx.event.ActionEvent;
import javafx.fxml.FXML;
import javafx.scene.control.Button;
import javafx.scene.control.Label;

public class MainController {

    @FXML
    private Label display;

    private double firstOperand = 0;
    private String currentOperator = "";
    private boolean startNewNumber = true;

    // Ввод цифр (0-9) - общий метод для всех цифровых кнопок
    @FXML
    void onDigitClick(ActionEvent event) {
        Button btn = (Button) event.getSource();
        String digit = btn.getText();

        if (startNewNumber || display.getText().equals("0")) {
            display.setText(digit);
            startNewNumber = false;
        } else {
            display.setText(display.getText() + digit);
        }
    }

    // Ввод десятичной точки
    @FXML
    void onDot() {
        if (startNewNumber) {
            display.setText("0.");
            startNewNumber = false;
        } else if (!display.getText().contains(".")) {
            display.setText(display.getText() + ".");
        }
    }

    // Выбор арифметической операции (+, -, *, /)
    @FXML
    void onOperator(ActionEvent event) {
        Button btn = (Button) event.getSource();
        
        // Если уже была начата цепочка вычислений - сначала вычисляем результат
        if (!currentOperator.isEmpty() && !startNewNumber) {
            calculate();
        }

        try {
            firstOperand = Double.parseDouble(display.getText());
        } catch (NumberFormatException e) {
            firstOperand = 0;
        }

        currentOperator = btn.getText();
        startNewNumber = true;
    }

    // Нажатие кнопки "="
    @FXML
    void onEquals() {
        if (!currentOperator.isEmpty()) {
            calculate();
            currentOperator = "";
            startNewNumber = true;
        }
    }

    // Вспомогательный метод вычисления
    private void calculate() {
        try {
            double secondOperand = Double.parseDouble(display.getText());
            double result = 0;

            switch (currentOperator) {
                case "+":
                    result = firstOperand + secondOperand;
                    break;
                case "-":
                    result = firstOperand - secondOperand;
                    break;
                case "*":
                    result = firstOperand * secondOperand;
                    break;
                case "/":
                    if (secondOperand == 0) {
                        display.setText("Ошибка");
                        currentOperator = "";
                        startNewNumber = true;
                        return;
                    }
                    result = firstOperand / secondOperand;
                    break;
                default:
                    return;
            }

            // Форматируем вывод: убираем лишние нули (.0), если число целое
            if (result == (long) result) {
                display.setText(String.format("%d", (long) result));
            } else {
                display.setText(String.valueOf(result));
            }

            firstOperand = result;

        } catch (NumberFormatException e) {
            display.setText("Ошибка");
        }
    }

    // Очистка (кнопка C)
    @FXML
    void onClear() {
        display.setText("0");
        firstOperand = 0;
        currentOperator = "";
        startNewNumber = true;
    }

    // Смена знака (+/-)
    @FXML
    void onToggleSign() {
        try {
            double value = Double.parseDouble(display.getText());
            if (value != 0) {
                value = -value;
                if (value == (long) value) {
                    display.setText(String.format("%d", (long) value));
                } else {
                    display.setText(String.valueOf(value));
                }
            }
        } catch (NumberFormatException ignored) {
        }
    }

    // Процент (%)
    @FXML
    void onPercent() {
        try {
            double value = Double.parseDouble(display.getText()) / 100.0;
            display.setText(String.valueOf(value));
            startNewNumber = true;
        } catch (NumberFormatException ignored) {
        }
    }
}
```

```css
}
```

## 5. Тестирование

1. Запустите проект через `App.java` (клавиша **F5** или кнопка **Run**).
2. Проверьте:
   - Ввод многозначных чисел (`1`, `2`, `3` ➔ `123`);
   - Дробные числа (`5`, `.`, `2` ➔ `5.2`);
   - Сложение и умножение: `7 + 8 = 15`;
   - Последовательные операции: `5 * 4 = 20 - 5 = 15`;
   - Деление на 0 ➔ вывод слова «Ошибка»;
   - Очистка по кнопке `C` ➔ возврат дисплея в `0`.
