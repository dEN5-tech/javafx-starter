# ☕ JavaFX — Минимальный стартовый шаблон для студентов (с нативным расширением Auto-Sync)

Ультра-простой шаблон JavaFX для работы с **Scene Builder** и **Extension Pack for Java** в VSCodium / VS Code без ошибок на Windows 10 и Windows 11.

---

## 🚀 Как запускать проект

1. Откройте файл `src/com/example/App.java`.
2. Нажмите **зелёный треугольничек запуска ▶** в правом верхнем углу редактора (или кнопку **`Run`** над `public static void main`).
3. Приложение запустится без ошибок!

## ⚡ Нативное расширение «JavaFX Controller Auto-Sync» (Без лишнего интерфейса)

В комплект воркспейса включено специальное легковесное расширение VSCodium:
```text
extensions/vscode-javafx-sync-1.1.0.vsix
```

### Как оно работает:
- **Полная автоматика в фоне**: не требует запуска терминалов, скриптов, кнопок переключения и лишних панелей.
- При сохранении любого `.fxml` файла (в Scene Builder или в редакторе по `Ctrl+S`):
  1. Расширение само находит связанный Java-контроллер (`MainController.java`).
  2. Добавляет все новые `@FXML private ...` поля и заготовки методов событий.
  3. Аккуратно прописывает нужные импорты, сохраняя весь ваш написанный код.
  4. В строке состояния (внизу окна VSCodium) тихо показывает:
     `$(sync) JavaFX: MainController.java auto-synced`
- При желании можно вызвать ручную синхронизацию через палитру команд: `Ctrl+Shift+P` → **`JavaFX: Sync Controllers from FXML`**.

## 🎨 Как работать в Scene Builder

1. Откройте файл **`src/com/example/MainView.fxml`** в Scene Builder:
   - Через меню VSCodium: **Terminal → Run Task... → 🎨 Открыть макет в Scene Builder**.
   - Либо через скрипт `tools\open-scenebuilder.bat`.
2. Перетаскивайте компоненты из левой палитры на макет.
3. Указывайте элементам **fx:id** (например, `ageField`) и **On Action** (например, `onCalculate`).
4. Нажмите **Ctrl+S** в Scene Builder.
5. Переключитесь в VSCodium — **все поля и методы уже добавлены в контроллер автоматически!**

## ✨ Автоформатирование кода при сохранении

- При нажатии **Ctrl+S** (сохранение) VSCodium выравнивает отступы, расставляет скобки и форматирует код.
- Автоматически оптимизируются импорты (`Organize Imports`).

## 📁 Структура (только самое нужное)

В проводнике VSCodium скрыты служебные папки (SDK, байткод, скрипты). Студент видит только рабочую зону:

```text
src/
└── com/example/
    ├── App.java            ← Точка запуска приложения (жмем ▶)
    ├── Launcher.java       ← Резервный лаунчер
    ├── MainController.java ← Логика и обработчики (код)
    ├── MainView.fxml       ← Вёрстка интерфейса (Scene Builder)
    └── style.css           ← Стили CSS (по желанию)
```
